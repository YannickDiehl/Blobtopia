# Blobtopia

Blobtopia ist das Vue.js-Frontend einer sozialen Simulation, in der Studierende eine Gesellschaft aus kugelförmigen Wesen — den **Blobs** — beobachten und erforschen. Das Projekt ist Teil des **Globtopia-Lehrkonzepts** für das Proseminar *Methoden I* (B.A.) an der Philipps-Universität Marburg.

## Tech-Stack

- **Vue 2** mit Vuex und Vue Router
- **Three.js** für die 3D-Visualisierung der Blob-Welt
- **Buefy / Bulma** für UI-Komponenten
- **Chart.js** für Datenvisualisierungen

## Setup

```bash
npm install
npm run dev
```

Die App läuft dann unter `http://localhost:8080`.

## Build

```bash
npm run build
```
